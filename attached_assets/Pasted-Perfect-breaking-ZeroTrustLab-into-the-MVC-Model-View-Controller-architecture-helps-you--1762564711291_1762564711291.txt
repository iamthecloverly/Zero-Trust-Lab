## 🧩 **ZeroTrustLab – MVC Architecture Overview**

**Goal:**
A web app that visually simulates **Zero Trust access control** — showing which network connections are allowed, denied, or challenged (MFA/geo-blocking).
Users can dynamically toggle policies and instantly see how network trust decisions change in real time.

---

### 🧱 **MODEL (Data + Logic Layer)**

The Model represents your **core Zero Trust logic** — devices, users, policies, and trust evaluations.

**Language/Framework:** Python (FastAPI backend + `networkx` or `neo4j`)

**Responsibilities:**

* Store and manage **network entities** (devices, users, applications, connections).
* Define and enforce **Zero Trust policies** — e.g., MFA required, region restrictions, least privilege access.
* Compute **trust decisions** for every connection (Allow / Deny / Challenge).
* Maintain simulation state and relationships.

---

#### **Model Components:**

**1️⃣ Entities (Data Models):**

```python
# models/entities.py
from pydantic import BaseModel

class Device(BaseModel):
    id: str
    type: str        # e.g., "Laptop", "Server"
    location: str
    verified: bool

class User(BaseModel):
    id: str
    role: str        # e.g., "Admin", "Employee"
    mfa_enabled: bool

class Connection(BaseModel):
    source: str
    target: str
    action: str      # e.g., "read", "write"
```

**2️⃣ Zero Trust Policy Engine:**

```python
# models/policy_engine.py
def evaluate_connection(user, device, connection, policy_rules):
    # Base trust = 100
    score = 100
    if not device.verified:
        score -= 40
    if not user.mfa_enabled:
        score -= 30
    if device.location not in policy_rules["allowed_regions"]:
        score -= 20
    if user.role not in policy_rules["permitted_roles"]:
        score -= 10

    if score >= 70:
        return "ALLOW"
    elif score >= 40:
        return "CHALLENGE_MFA"
    else:
        return "DENY"
```

**3️⃣ Graph Simulation:**

```python
# models/network_graph.py
import networkx as nx

class NetworkGraph:
    def __init__(self):
        self.G = nx.Graph()

    def add_node(self, node_id, node_type):
        self.G.add_node(node_id, type=node_type)

    def add_connection(self, src, dest):
        self.G.add_edge(src, dest, status="UNKNOWN")

    def update_edge_status(self, src, dest, verdict):
        self.G[src][dest]["status"] = verdict
```

### ⚙️ **CONTROLLER (Business Logic + Flow Coordinator)**

The Controller links the backend (Model) with the frontend (View).
It handles user actions (policy toggles, device status changes) and returns simulation updates.

**Language/Framework:** Python (FastAPI)

**Responsibilities:**

* Receive user input via API requests (policy settings, node actions).
* Execute the Zero Trust policy engine.
* Return results (access verdicts + graph status updates) as JSON for visualization.
* Optionally store audit logs for replay.

---

#### **Controller Example:**

```python
# controllers/simulation_controller.py
from fastapi import APIRouter
from models.entities import User, Device, Connection
from models.policy_engine import evaluate_connection
from models.network_graph import NetworkGraph

router = APIRouter()
graph = NetworkGraph()

policy_rules = {
    "allowed_regions": ["US", "CA"],
    "permitted_roles": ["Admin", "Engineer"]
}

@router.post("/simulate")
def simulate_connection(user: User, device: Device, connection: Connection):
    verdict = evaluate_connection(user, device, connection, policy_rules)
    graph.add_node(user.id, "user")
    graph.add_node(device.id, "device")
    graph.add_connection(user.id, device.id)
    graph.update_edge_status(user.id, device.id, verdict)
    return {"verdict": verdict, "graph": nx.node_link_data(graph.G)}
```

### 🖥️ **VIEW (Presentation Layer)**

The View (React Frontend on Vercel) renders the entire simulation visually — showing real-time updates of trust decisions, access paths, and device status.

**Language/Framework:** React + D3.js / Cytoscape.js (for network visualization)

**Responsibilities:**

* Interactive dashboard for:

  * Uploading or generating network maps
  * Modifying Zero Trust rules (toggle MFA, geo-blocking, etc.)
  * Displaying visual graph (nodes = users/devices, edges = connections)
  * Color-coding edges based on verdicts
* Real-time API interaction with FastAPI backend (`/simulate` endpoint).

#### **View Example (React)**

```jsx
// components/NetworkGraph.js
import React, { useState } from "react";
import axios from "axios";
import Graph from "react-vis-network-graph";

const NetworkGraph = () => {
  const [data, setData] = useState({ nodes: [], edges: [] });

  const simulate = async () => {
    const res = await axios.post("https://api.zerotrustlab.com/simulate", {
      user: { id: "U1", role: "Engineer", mfa_enabled: false },
      device: { id: "D1", type: "Laptop", location: "IN", verified: false },
      connection: { source: "U1", target: "D1", action: "access" }
    });
    const newGraph = res.data.graph;
    setData({
      nodes: newGraph.nodes.map(n => ({ id: n.id, label: n.id })),
      edges: newGraph.links.map(e => ({
        from: e.source, to: e.target,
        color: e.status === "DENY" ? "red" :
               e.status === "CHALLENGE_MFA" ? "orange" : "green"
      }))
    });
  };

  return (
    <div>
      <button onClick={simulate}>Simulate Access</button>
      <Graph graph={data} options={{ height: "600px" }} />
    </div>
  );
};

export default NetworkGraph;
```

## 🧭 **Data Flow (MVC Interaction)**

1. **User action** → toggles policy or simulates a connection on the React UI
2. **Controller** (FastAPI) → receives request, applies Zero Trust policy
3. **Model** → evaluates connection and updates graph state
4. **Controller** → returns updated graph and verdict
5. **View** → re-renders the network map with color-coded trust decisions

```
[User Action] → [View: React UI] → [Controller: FastAPI] → [Model: Policy Engine + Graph]
                                   ↑                                           ↓
                             JSON Response ← Verdict + Graph Data
```
